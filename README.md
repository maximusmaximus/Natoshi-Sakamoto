# Natoshi Sakamoto

Coming soon. Nothing is public yet.

The live page collects launch notes only after an explicit opt-in:

- The subscribe box starts unchecked.
- A submission without that consent is rejected.
- Each opt-in is stored as its own text file in the Google Drive folder **Natoshi Sakamoto Subscribers**, with the address, optional name, the exact consent sentence, time, timezone, locale, user agent, and referrer.
- A confirmation is sent from the connected Gmail account. Replying to it is how someone leaves the list.

Public repository: https://github.com/maximusmaximus/Natoshi-Sakamoto

This repository is the public record of the project. The page itself runs with the publisher’s Google Drive and Gmail connected, so addresses are not committed here.
